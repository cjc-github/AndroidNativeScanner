Web 控制台如何工作

py -3 web/server.py        # 启动服务并自动打开浏览器
soinsight scan TARGET --enable basic.elf,basic.symbols --format json   # 页面每次运行等价于这条 CLI

页面通过 /api/analyze 把目标交给本地服务，服务以子进程执行上面的 CLI 并回传 JSON；服务仅绑定 127.0.0.1，上传文件只写入系统临时目录、分析后即删。命令行用法见 docs/quickstart.md。

页面还无法调用分析：未连接到本地分析服务

浏览器里的 HTML 自己不能执行本机的 Python 分析。请先在项目目录启动本地服务，再刷新本页：

Windows：双击 web\start-web.bat
任意平台：py -3 web/server.py          # 启动并自动打开浏览器
指定端口：py -3 web/server.py --port 9000

推荐用 py -3（Python 3.10）而不是裸 python：本机默认的 Python 3.13 未安装依赖 PyYAML，用它会启动失败。

服务只绑定 127.0.0.1，不会把本机文件暴露到局域网；分析由服务以子进程方式调用 python -m soinsight 完成。
