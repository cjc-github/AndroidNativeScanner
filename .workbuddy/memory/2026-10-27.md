## 第二轮：服务端安全与体验缺口（用户要求"还有什么需要修改，修改并提交"）

审查又发现 6 个问题，全部修掉：

**安全**
- `web/server.py` 静态路由原本不限扩展名，`GET /server.py`、`/start-web.bat`、`/__pycache__/*.pyc` 都能直接下载源码（实测 200，31KB）。改成只放行 `CONTENT_TYPES` 里的扩展名，其余 404。注意 `main()` 在检测到 `PORT` 环境变量时会 bind 0.0.0.0，所以这不只是本机问题。
- `Content-Length` 头未做异常处理，`int()` 遇到脏值会抛异常中断处理；补 400 与负数校验。
- 导出的 CSV 做了公式注入转义（`= + - @` 开头加前缀 `'`）。

**体验**
- `POST /api/cancel`：`_run_analysis` 从 `subprocess.run` 改为 `Popen` + 0.2s 轮询，把进程登记到 `_RUN_STATE`，取消接口 kill 子进程并让请求返回「分析已取消」，而不是让用户干等满 180 秒。UI 运行中出现「停止分析」按钮，取消用中性提示色（`#error-box.notice`）而非红色报错。
- 超时上限来自 `/api/health` 的 `analysis_timeout_seconds`，计时显示「已用 X s / 上限 Y s」。
- 勾选的能力 + 服务器路径存 `localStorage`（`soinsight.console.prefs.v1`），刷新自动恢复；上传的 File 无法序列化，不持久化。
- 符号表（按当前筛选）与发现项可导出 CSV，带 UTF-8 BOM。
- Tab 补 `aria-selected` + roving tabindex（此前只切 class）。

**文档/脚本**
- `web/start-web.bat` 优先用 `py -3`（本机默认 `python` 是没装 PyYAML 的 3.13），并转回 CRLF。
- `server.py` docstring 与子进程报错里残留的 `site/server.py` 全部改成 `web/server.py`。
- README 新增「本地 Web 控制台」章节 + 目录树补 `web/`；`feature-status.md` 补取消/白名单/导出/持久化说明，测试数 405→468。
