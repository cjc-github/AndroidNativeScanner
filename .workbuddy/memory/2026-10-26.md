### 交付：本地 Web 控制台（site/）
- `site/server.py`（stdlib-only HTTP 服务，约 17KB）：
  - `/` 服务 `index.html`；`/api/health`、`/api/modules`、`/api/samples`、`/api/analyze`
  - `/api/analyze`：支持 mode=single（capability=）+ scan（modules=）；目标来源二选一——query `path=`（服务器绝对路径，做路径安全校验 + traversal 拒绝）/ 请求体二进制上传（header `X-Filename`）
  - 后端子进程调用 `python -m soinsight`（`PYTHONPATH=src`，`--format json --no-cache --quiet`），解析 stdout 为 ScanResult payload 原样回传
  - 错误处理：未知能力→400；相对/非法路径→400；目录穿越→403；非 ELF→退出码 5、诊断 `INVALID_ELF`；依赖自动展开（如 basic.elf 自动拉 basic.file）
  - 仅监听 `127.0.0.1`，无外部依赖
- `site/index.html`（约 54KB，自包含，node --check 通过）：交互式分析工作台
  - 目标选择：拖拽上传 / 服务器路径 / 样本下拉（`in/`）
  - 能力选择：6 个已实现单能力 + `scan --module-available basic,security` 组合
  - 结果渲染：ELF 头 / 文件指纹 / 符号表（含 demangle、JNI 计数）/ 加固发现项 / 危险 API / DWARF / 原始 JSON tab；状态徽章、诊断、下载 JSON
- `site/start-web.bat`：Windows 双击启动（等价于 `python site/server.py`）
