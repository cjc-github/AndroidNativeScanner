Web 控制台如何工作

        

          
python site/server.py        # 启动服务并自动打开浏览器

          
soinsight basic elf TARGET --format json   # 页面每次运行等价于这条 CLI

        

        
页面通过 /api/analyze 把目标交给本地服务，服务以子进程执行上面的 CLI 并回传 JSON；服务仅绑定 127.0.0.1，上传文件只写入系统临时目录、分析后即删。命令行用法见 docs/quickstart.md。
