# SOInsight V3.0 设计占位说明

> 当前尚未启动独立的 V3 产品设计。

SOInsight 现阶段的主设计已经收敛到 [`design_v2.0.md`](design_v2.0.md)。原先放在本文件中的“V2 CLI 工具箱优化设计”已合并回 V2 主设计，避免出现“V2 是能力清单、V3 才是实际架构”的版本错位。

## 使用约定

- 当前实现、模块边界、CLI、设计模式和 Roadmap：以 [`design_v2.0.md`](design_v2.0.md) 为准；
- V1 历史规划：参见 [`design_v1.0.md`](design_v1.0.md)；
- 只有在产品边界、兼容策略或核心架构发生不兼容升级时，才在本文件启动 V3 设计；
- V2 内部的功能扩展、Analyzer 增加和文档完善，不自动升级为 V3。

## V3 启动条件

满足以下任一条件时，再建立正式 V3 SDS：

1. 六大产品能力域发生不兼容调整；
2. CLI 稳定命令或结果 Schema 发生大版本不兼容；
3. 从本地模块化单体转向服务化/分布式架构；
4. 插件协议或 Unified IR 需要大版本迁移。
