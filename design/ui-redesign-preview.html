本预览采用的设计方案

来自 UI 设计知识库；确认后按同一套语义变量落到 console.css
  • 配色配色方案：霓虹暗黑 — 近黑底 + 霓虹青主色，发光只压主按钮；深色块之间必须描 1px 白 16% 边
  • 配色配色方案：蔚蓝科技 — 右上角可切换的浅色对照版：蓝青主色 + 冷白底 + 渐变主按钮
  • 导航侧边栏导航 — 左侧竖排分组导航，当前项品牌色 + 9% 淡底 + 左侧竖条
  • 动画数字滚动 — 关键指标翻牌滚轮，460ms，9→0 多滚一圈，闪一下品牌色
  • 数据迷你趋势线 Sparkline — 7 天小折线 + 渐变面积 + hover 气泡与虚线引导
  • 数据环形图 Donut Chart — 4 段占比、段间 2.4px 缝、段/图例联动中心数值
  • 数据数据表格 — 表头排序 + FLIP 位移动画 + 状态徽标 + 首列固定
